# Quiz Ειδικής Φυσικής Αγωγής

Διαδραστική αυτοαξιολόγηση για φοιτητές, βασισμένη στη διάλεξη «Η συμβολή της Ειδικής Φυσικής Αγωγής στη λειτουργικότητα και στην αυτονομία ατόμων με αναπηρία».

- 7 ερωτήσεις πολλαπλής επιλογής, με μία σωστή απάντηση ανά ερώτηση.
- Ξεχωριστή βοήθεια πριν από την απάντηση και 28 αιτιολογήσεις, μία για κάθε σωστή ή λανθασμένη επιλογή.
- Ανασκόπηση όλων των επιλογών, σκορ και επανάληψη.
- Ελληνικά, σχεδιασμός για κινητά, εγγενή radio buttons και πλοήγηση με πληκτρολόγιο.
- Χωρίς λογαριασμό, συλλογή απαντήσεων, cookies ή εξωτερικές βιβλιοθήκες εκτέλεσης.

## Δημοσίευση

GitHub Pages από `main`, φάκελος `/`. Το αρχείο `.nojekyll` διατηρεί τη φιλοξενία ως στατικό site.

- Quiz: https://giorgosbouh.github.io/demo_teaching_quiz/
- Σελίδα προβολής QR: https://giorgosbouh.github.io/demo_teaching_quiz/share.html
- QR SVG: https://giorgosbouh.github.io/demo_teaching_quiz/assets/quiz-qr.svg

## Τοπική χρήση

Σέρβιρε τον φάκελο με οποιονδήποτε απλό HTTP server. Δεν απαιτείται build. Για τους ελέγχους περιεχομένου εκτέλεσε `npm test` με πρόσφατη Node.js.

Οι ερωτήσεις και οι εξηγήσεις βρίσκονται στο `quiz-data.js`. Οι σωστές απαντήσεις είναι ορατές στον κώδικα, όπως αρμόζει σε quiz αυτοαξιολόγησης· δεν προορίζεται για εξετάσεις με ασφαλή βαθμολόγηση.
